This is the editable profile × phase coefficient matrix (v14.8): each product profile (Greenfield, Feature add, Maintenance, Modernisation — plus the End-of-life benchmark, which maps to Maintenance) carries one coefficient per phase, applied to the phase’s effort point. The same coefficients drive the Product-status weighting and the Eligibility potential matrix — one source of truth. Edit the per-phase coefficients and the automation posture for each profile. These are the benchmarks the lifecycle axis interpolates between — changes cascade live to the Scope catalogue, the cascade preview and the whole business case. Values are colour-coded: green >1 (more effort/automation), red <1 (less). Amber border = edited vs default.
