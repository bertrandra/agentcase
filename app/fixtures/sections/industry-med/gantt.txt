One shared calendar, dates from the 🧭 AI Readiness roadmap. Program rows run in real time (incl. 🧠 Knowledge Hub build/setup + run when enabled). Delivery rollout places every in-scope participant — phases and 🔶 Cross-cutting — on the same calendar in ramp-up (seq) order, each sized by its own effort weight (w = effort × lifecycle) and compressed as automation ramps — later work is shorter for the same weight (velocity ×1 → ×4.00). Two participants sharing the same seq number start together (a synchronised wave); otherwise they overlap/pipeline by the % above. This is pipelining — different artefacts sitting in different phases at the same time, not a shortcut through the work — so a full pass (spec → … → verify, plus cross-cutting) for the in-scope backlog only actually completes at the 🏁 marker: that point is the release. Each row shows the translucent activity span and the solid human-supervision subset. ▶ expand a phase or 🔶 Cross-cutting for its SDLC (📄) and regulatory (⚖️) artefacts — the same seq-tie rule applies one level down: artefacts sharing a seq value also start together.
