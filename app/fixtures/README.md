# Oracle fixtures

Generated by `node tools/oracle.mjs` from the **legacy** single-file app (v18.11). Do not edit by hand.

- `cases/<id>.json` — the full snapshot state of the case (what `collectSnapshotState()` returns, without the calculation package
  and the snapshot library): the input of the new engine.
- `expected/<id>.json` — what the legacy engine computes from it: `model()`, canonical payback / NPV, headline, scope averages,
  glass ceiling, audit result. This is the contract of `app/src/domain`.

Recipes live in `tools/oracle-recipes.mjs`. Regenerate only when a legacy calculation change is deliberate (decision D7: calculation
changes ship in the legacy file first so the oracle moves with them).
